请帮我将当前的字幕弹窗（SubtitleWindow）重构/升级为一个独立模块化的「Galgame 风格对话框组件（Dialog Presenter）」。

### 一、 定位与架构设计原则
1. **职责边界**：它仅仅是一个前端 Presenter，只负责 UI 呈现与用户交互，绝不侵入 Runtime 业务逻辑。
2. **极简主义（精简）**：摒弃游戏引擎的重型概念（无 Save/Load、无场景管理器、无复杂渲染管线）。
3. **可扩展接缝（Seam 设计）**：采用模块化拆分，为未来可能的拓展（立绘显示、分支交互、音频控制）预留干净接口，避免破坏核心逻辑。

---

### 二、 详细功能与交互需求

#### 1. 模块化解耦与结构拆分
- 将对话框拆分为 `DialogWindow`（视图容器）、`TextPresenter`（文本/打字机效果）、`AudioPresenter`（音频同步播放）、`DialogLogView`（履历视图）与 `DialogTheme`（主题样式与布局）。
- 提取 `IDialogPresenter` 接口，以便后续替换不同外观或 UI 框架。

#### 2. UI 与体验升级（Galgame 风格）
- **流式打字机效果**：实现平滑的文本逐字打印（Typing effect），适配 v2 的 SSE chunked 流式文本输入，消除卡顿感。
- **视觉控制**：优化字幕停留与倒计时平滑淡出（Fade-out）动画，消除生硬的消失体验。

#### 3. 生命周期与交互模式重构（常驻/Hold 模式）
- **改变“播完即灭”的行为**：语音与文本打印结束后，对话框默认**保持显示**（Hold 状态），并展示待机/等待输入指示器（如闪烁光标）。
- **关闭/隐藏触发**：
  - 支持点击对话框区域或按下全局快捷键触发淡出隐藏（Fade-out）。
  - 若开启了自动隐藏倒计时，当鼠标悬停在对话框上方时，必须**挂起/冻结倒计时**，移出后恢复。
  - 预留 Pin（钉住）常驻控制，避免连续对话过程中的界面频繁闪烁。

#### 4. 全局快捷键支持（托盘程序集成）
- **托盘程序集成**：全局快捷键的注册、监听与管理统一放在托盘程序（VoiceCoreTray）中实现。
- **自定义按键**：支持用户自定义快捷键（如隐藏/呼出对话框、切换待机状态、打开 Log 履历）。

#### 5. 会话历史与音频重播（Galgame Log 系统）
- **Log 视图组件**：新增/重构 `DialogLogView`，允许用户通过界面按钮、快捷键或向上滚轮呼出历史对话履历。
- **音频重播与缓存调查**：
  - 每条 Log 记录关联对应的 `audioId`，允许用户点击重播语音。
  - **缓存边界调查**：请先调查 Rust 侧（spool 模块）当前的音频缓存与清理策略（如固定条数、磁盘容量或内存留存）。
  - 前端 Log 列表可保留最近 N 条文本，但重播按钮需根据后端缓存状态动态展示；若后端音频已清除，重播按钮应显示禁用状态或给予优雅提示。

#### 6. 预留扩展接口（Future Extensions）
- **Character / Avatar Seam**：预留角色头像/立绘接口（`SetCharacter(string name, string avatarUrl/expression)`），目前可为空或隐藏。
- **Control Event Seam**：预留控制事件回调（如语速调节、音量调节、分支选项点击事件），统一通过事件总线或回调派发给 `RuntimeClient`。

### 三、 执行步骤与要求
1. **先调查与设计**：请先调查 Rust 侧 `spool` 缓存机制与 API 状态，给出一份简要的 C# UI 架构拆分与方案说明。
2. **渐进式编写**：在确定 API 和边界后再编写 C# UI 代码，保持模块间低耦合。
3. **代码规范**：保持代码干净且符合现代 C#/WinUI3 规范，不要引入无关的重型依赖。

**Q: Galgame 对话框 + WinUI 3 + Windows 11 美学融合的必备要素与设计方案**

**A:** 将经典 Galgame 的沉浸感与 Windows 11 现代 Fluent Design 结合，核心在于“剔除复古游戏框架的笨重感，保留文本呈现的仪式感，同时赋予 Windows 原生应用的高级质感”。

---

### 一、 必备要素清单

* **云母/亚克力材质（Mica Alt / Acrylic）**：采用 Win11 标志性的半透明材质与背景磨砂微透效果，替代传统的纯色或高对比度贴图。
* **圆角与微阴影（Corner Radius & Soft Shadows）**：遵循 Win11 标准圆角（如 `8px - 12px`），结合多层柔和 DropShadow，让对话框轻浮于桌面之上。
* **流式打字机与平滑过渡（Typing & Fade Transitions）**：搭配定长/平滑淡入的文本打印节奏，配合字符位移微动画，消除视觉上的突然跳变。
* **动态待机指示器（Wait Indicator / Click-to-Continue）**：文字打印完毕后呈现的闪烁小三角或呼吸微光，传递 Galgame 经典的“等待交互（Hold）”信号。
* **沉浸式非标题栏拖拽（Non-Client Area Dragging）**：移除传统 Windows 标题栏，将整个对话框或顶部隐形手柄区设为拖拽源，结合无边框（Borderless）形态。
* **上下文感知控制（Contextual Micro-Controls）**：将重播（Replay）、Log 履历、Pin 钉住、关闭（X）等控制按钮半透明收纳在对话框边缘或鼠标悬停时激活（Hover Reveal）。

---

### 二、 具体设计方案

#### 1. 视觉分层与布局（Visual Hierarchy）

```
+-----------------------------------------------------------------------+
|  [角色/系统 Icon]  角色名 (Speaker Name)              [Pin] [Log] [X]  |  <-- 隐形拖拽手柄区 (Drag Strip)
+-----------------------------------------------------------------------+
|                                                                       |
|  “对话文本 / TTS 字幕流内容，采用 Fluent 字体与高清晰度字间距……”       |  <-- 响应点击的主体区域 (Body Region)
|                                                                       |
|                                                                 ▼     |  <-- 呼吸灯指示器 (Wait Indicator)
+-----------------------------------------------------------------------+

```

* **背景底板**：使用 WinUI 3 的 `MicaBackdrop` 或 `DesktopAcrylicBackdrop`，叠加一层 `0.6` 透明度的深色/浅色遮罩，确保任意桌面背景下文本的阅读对比度。
* **字体排版**：优先使用 `Segoe UI Variable` 或 `Microsoft YaHei UI`，加大行高（`LineHeight = 1.4`）与字间距，呈现类似小说修饰的精致感。

#### 2. XAML 结构与 WinUI 3 特性实现

在 WinUI 3 中，利用 `Grid` 布局与 `ThemeResources` 可以快速搭建一套符合 Windows 11 规范的样式：

```xml
<Window
    x:Class="VoiceCoreTray.Dialog.DialogWindow"
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">

    <!-- 挂载 Win11 云母/亚克力背景 -->
    <Window.SystemBackdrop>
        <DesktopAcrylicBackdrop />
    </Window.SystemBackdrop>

    <Border CornerRadius="12"
            Background="{ThemeResource SystemControlAcrylicElementBrush}"
            BorderBrush="{ThemeResource SurfaceStrokeColorDefaultBrush}"
            BorderThickness="1"
            Margin="10">
        <Grid RowDefinitions="Auto,*">
            
            <!-- 顶部拖拽手柄与微型控制栏 -->
            <Grid Grid.Row="0" x:Name="DragHandleStrip" Height="32" Padding="12,4">
                <StackPanel Orientation="Horizontal" VerticalAlignment="Center">
                    <TextBlock x:Name="SpeakerName" Text="System" 
                               FontWeight="SemiBold" FontSize="12" 
                               Foreground="{ThemeResource AccentTextFillColorPrimaryBrush}"/>
                </StackPanel>

                <!-- 悬浮控制按钮组 -->
                <StackPanel Orientation="Horizontal" HorizontalAlignment="Right" Spacing="4">
                    <Button Style="{StaticResource TitleBarButtonStyle}" x:Name="LogButton" Content="&#xE81C;" ToolTipService.ToolTip="对话履历"/>
                    <Button Style="{StaticResource TitleBarButtonStyle}" x:Name="PinButton" Content="&#xE718;" ToolTipService.ToolTip="固定窗口"/>
                    <Button Style="{StaticResource TitleBarButtonStyle}" x:Name="CloseButton" Content="&#xE711;" ToolTipService.ToolTip="隐藏"/>
                </StackPanel>
            </Grid>

            <!-- 文本主体区域 (点击可隐藏/推进) -->
            <Grid Grid.Row="1" x:Name="BodyRegion" Padding="16,8,16,16" Background="Transparent">
                <TextBlock x:Name="DialogText" 
                           TextWrapping="Wrap" 
                           FontSize="15" 
                           LineHeight="22"
                           Foreground="{ThemeResource TextFillColorPrimaryBrush}"/>
                
                <!-- Galgame 等待输入指示器 -->
                <FontIcon x:Name="WaitIndicator" 
                          Glyph="&#xE0E5;" 
                          FontSize="10"
                          HorizontalAlignment="Right" 
                          VerticalAlignment="Bottom"
                          Margin="0,0,4,0"/>
            </Grid>
        </Grid>
    </Border>
</Window>

```

#### 3. 交互细节与 UX 优化

* **事件隔离设计**：将拖拽区域（`DragHandleStrip`）与点击区域（`BodyRegion`）在事件响应上独立。点击 `BodyRegion` 触发“隐藏/下一句”，拖拽 `DragHandleStrip` 触发窗口移动，避免移动窗口时误关闭。
* **微动画（Micro-animations）**：
* **WaitIndicator**：使用 `Composition` API 或 `Storyboard` 绑定 `Opacity` 呼吸灯动画（从 `0.2` 到 `1.0` 循环淡入淡出）。
* **窗口显示/淡出**：显示时使用 `ConnectedAnimation` 或简单的 Scale & Opacity 组合微动（从 98% 缩放平滑过渡至 100%）。


* **Log 履历抽屉（Flyout / Sheet）**：点击 Log 按钮或向上滚动滑轮时，从对话框上方平滑展开一个基于 `ListView` 的半透明履历面板，支持点击历史项重播 TTS 音频。
